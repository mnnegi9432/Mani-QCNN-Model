Research Contribution

This Hybrid Deep Feature Extraction and Quantum Learning Framework integrates EfficientNet-B0, StandardScaler, Principal Component Analysis (PCA), and a Hybrid Quantum Convolutional Neural Network (Hybrid QCNN) to perform automated multi-class brain tumor classification using MRI images.

The proposed framework combines the feature learning capability of deep neural networks with the computational advantages of hybrid quantum learning, providing an efficient pipeline for intelligent medical image analysis.
