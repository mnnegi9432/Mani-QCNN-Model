About the Project

This web application presents a Hybrid Deep Feature Extraction and Quantum Learning Framework for automated brain tumor classification using Magnetic Resonance Imaging (MRI).

The framework integrates EfficientNet-B0, StandardScaler, Principal Component Analysis (PCA), and a Hybrid Quantum Convolutional Neural Network (Hybrid QCNN) to classify MRI images into four tumor categories.
