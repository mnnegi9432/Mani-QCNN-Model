🧠 About Hybrid QCNN Brain Tumor Detection

An AI-powered medical decision support system for brain tumor classification using Deep Learning and Quantum Machine Learning.

📌 Project Overview

This project presents a Hybrid Brain Tumor Detection framework that combines EfficientNet-B0 with a Hybrid Quantum Convolutional Neural Network (QCNN) for MRI image classification. The workflow extracts deep visual features, standardizes them, reduces dimensionality using PCA, and performs quantum learning to classify MRI images into four categories.

🎯 Research Objective

Develop an intelligent diagnostic support system for early brain tumor classification using Hybrid Quantum Machine Learning to improve classification performance while reducing computational complexity.

📊 Model Information

Input Size 224 × 224 RGB
Deep Features 1280
PCA Output 16 Features
Quantum Encoding RY Angle Encoding
Quantum Layers 4 Variational Layers
Entanglement Ring CNOT
Measurement Pauli-Z

🧠 Output Classes

Glioma
Meningioma
Pituitary Tumor
No Tumor
